Press <kbd>?</kbd> in the app to show or hide this list as an overlay. Shortcuts are ignored while a dropdown is open or you are typing in a text field.

## Products

| Key | Product |
| --- | --- |
| <kbd>R</kbd> | Reflectivity |
| <kbd>V</kbd> | Velocity |
| <kbd>W</kbd> | Spectrum Width |
| <kbd>Z</kbd> | Differential Reflectivity |
| <kbd>C</kbd> | Correlation Coefficient |
| <kbd>P</kbd> | Differential Phase |
| <kbd>K</kbd> | Specific Differential Phase (KDP) |

## Navigation

| Key | Action |
| --- | --- |
| <kbd>←</kbd> / <kbd>→</kbd> | Previous / next site |
| <kbd>T</kbd> | Next tilt |
| <kbd>0</kbd> | Reset pan and zoom |
| <kbd>F</kbd> | Toggle fullscreen |

## Overlays

| Key | Action |
| --- | --- |
| <kbd>B</kbd> | Toggle borders |
| <kbd>W</kbd> | Toggle watches |
| <kbd>A</kbd> | Toggle warnings |
| <kbd>N</kbd> | Toggle tropical data |

> <kbd>W</kbd> is listed twice because in 0.10.2 one press does both: it selects Spectrum Width and toggles watches. Use the toolbar's Watches toggle to change watches on their own.

## Help and dialogs

| Key | Action |
| --- | --- |
| <kbd>?</kbd> | Show / hide shortcuts |
| <kbd>Esc</kbd> | Close the settings panel, an alert, or the shortcut overlay |

## Mouse

| Action | Result |
| --- | --- |
| Drag | Pan |
| Scroll wheel | Zoom |
| Double-click a site marker | Switch to that site |
| Double-click a warning polygon | Open the alert text |
